# Software license status

The original KAHM entry repository did not declare a repository-wide software
license. Version 0.1.0 does not assign a license on the copyright holders' behalf.

Public source availability and publication of a package do not, by themselves,
specify general reuse or redistribution permissions. Contact the maintainer,
Mohit Kumar, at mohit.kumar@uni-rostock.de for the intended software terms.

The related Koopman repository has its own license. That license is not assumed
to apply to this repository. Third-party dependencies and example datasets retain
their own terms and attribution; see [examples/README.md](examples/README.md).

A future explicit license decision should be recorded in a `LICENSE` file and in
the package metadata. This release is described as public research software,
without an open-source-license claim.
