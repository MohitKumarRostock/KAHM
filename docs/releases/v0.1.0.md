# KAHM v0.1.0: classification research preview

This release makes the KAHM entry repository installable and adds one fully
recorded classification example with familiar baselines.

## What is included

- `kahm.KAHMClassifier`: a scikit-learn adapter with samples-by-features inputs,
  in-memory fitting, preserved labels, and pipeline/grid-search compatibility.
- Installation instructions, a quickstart, a classifier guide, research links,
  citation metadata, and contribution guidance.
- Targeted numerical repairs for duplicate scoring work, Gaussian-query
  underflow, small affinity normalization, constant local references, and
  singleton-block prevention. Ordinary reconstructions are checked against
  the earlier formulas.
- A fixed-protocol Digits example comparing KAHM, logistic regression, RBF SVM,
  distance-weighted nearest neighbors, and an untuned dummy reference.

## Recorded classification example

The example uses all 1,797 bundled Digits observations and all 64 raw features.
It reserves 450 stratified test observations and selects each tuned model from
six configurations using the same three development folds. Scalers are fitted
inside the folds. All searches finish before test evaluation.

| Method | Held-out accuracy | Held-out balanced accuracy |
| --- | ---: | ---: |
| KAHM | 98.22% | 98.21% |
| Logistic regression | 97.11% | 97.11% |
| RBF SVM | 99.11% | 99.10% |
| k-nearest neighbors | 98.44% | 98.41% |
| Dummy reference | 10.22% | 10.00% |

KAHM correctly classifies 442 of 450 test images. The SVM and kNN scores are
retained in the report. This is one dataset and one split; it does not establish
a universal ranking or statistical significance.

Measured times describe a single run on the recorded environment.

## Installation

Download the wheel and install it with:

```bash
python -m pip install ./kahm-0.1.0-py3-none-any.whl
```

For the example, download and extract the source distribution, enter its folder,
then run:

```bash
python -m pip install ".[examples]"
python examples/classification.py --output-dir runs/digits
```

Use a new output directory; the runner protects existing result records.
Python 3.10 or newer is required. This is a GitHub research release, not a PyPI
publication. `SHA256SUMS` identifies the attached distribution files.

## Scope and license status

The normalized affinity scores returned by `predict_proba` do not establish
probability calibration. Signed-denominator cancellation can still produce
unstable reconstructions and is reported explicitly. Legacy regression and
optional quantum scripts are retained without a new validation claim.
